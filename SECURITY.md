# Security policy

## Supported versions

Only the latest release gets security fixes.

## Report a problem

Do not open a public issue for a security problem. Report it privately with GitHub private
vulnerability reporting: open the **Security** tab of this repo and click **Report a
vulnerability**, or go to
<https://github.com/tmathura/copilot-plugin-cc/security/advisories/new>.

Say which plugin version (`claude plugin list`) and which Copilot CLI version
(`copilot --no-auto-update --version`) you use, and how to see the problem. Do not
put tokens, passwords or other secrets in the report.

A problem in the GitHub Copilot CLI itself, not in this plugin, goes to GitHub, as its
[security policy](https://github.com/github/.github/blob/main/SECURITY.md) says.
